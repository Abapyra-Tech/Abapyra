# 🌿 Abapyra Tech

Plataforma web voltada para a sustentabilidade tecnológica, conectando pessoas, técnicos e projetos sociais para reaproveitar eletrônicos e reduzir o lixo eletrônico.

## 💡 Sobre o Projeto

A **Abapyra Tech** transforma o problema do lixo eletrônico em oportunidade de acesso à tecnologia, geração de renda e educação. A plataforma conecta doadores, técnicos, ONGs e estudantes em um ecossistema voltado para impacto social e sustentabilidade.

---

## 📄 Páginas

| Página | Arquivo | Descrição |
|---|---|---|
| Início | `index.html` | Hero, serviços, impacto e pilares |
| Serviços | `servicos.html` | Reparo técnico e cadastro de técnicos |
| Doações | `doacoes.html` | Doe eletrônicos e histórias de transformação |
| Receba Doações | `receba-doacoes.html` | Cadastro de ONGs e projetos sociais |
| Educação | `educacao.html` | Cursos gratuitos de tecnologia |
| Sobre | `sobre.html` | Missão, visão e valores |

## ⚙️ Tecnologias

- **HTML5, CSS3, JavaScript** — estrutura, estilo e interatividade
- **Fetch API** — carregamento dinâmico de header, footer e acessibilidade
- **VLibras** — tradução para Língua Brasileira de Sinais
- **Web Speech API** — leitura de tela nativa do navegador
- **ViaCEP** — busca de endereço por CEP
- **Font Awesome** — ícones
- **Google Fonts** — tipografia
- **Vercel** — hospedagem

---

## 🚀 Como Rodar Localmente

1. Clone o repositório
2. Abra a pasta no **VS Code**
3. Instale a extensão **Live Server**
4. Clique com o botão direito no `index.html` → **Open with Live Server**

> ⚠️ Não abra os arquivos diretamente no navegador. O projeto usa `fetch()` para carregar componentes, o que requer um servidor local.
