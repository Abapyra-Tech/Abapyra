# 🌿 Abapyra Tech

Plataforma web voltada para a sustentabilidade tecnológica, conectando pessoas, técnicos e projetos sociais para reaproveitar tecnologia e reduzir o lixo eletrônico.

---

## 📋 Sobre o Projeto

A **Abapyra Tech** é uma plataforma completa que une serviços de reparo, marketplace de eletrônicos usados, educação tecnológica e doações — tudo com foco em impacto social e cultural.

---

## 🚀 Como Rodar o Projeto

1. Clone ou baixe o repositório
2. Abra a pasta no **VS Code**
3. Instale a extensão **Live Server**
4. Clique com o botão direito no `index.html` → **Open with Live Server**

> ⚠️ O projeto usa `fetch()` para carregar o header e footer. Por isso é necessário rodar em um servidor local — não funciona abrindo o arquivo direto no navegador.
